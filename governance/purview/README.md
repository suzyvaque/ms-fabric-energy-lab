# Purview for the Contoso Energy lab (Step 9)

Sample, not production guidance. Tenant-specific values (label IDs, workspace IDs, UPNs) stay in `.env`, never here.

| Capability | What we do | How | Status in this lab | Licensing / prerequisites |
|---|---|---|---|---|
| **Sensitivity labels** | Label PII/financing items *Confidential*: `lh_finance`, `mir_loan_servicing`, `sm_finance`, `rpt_finance_kpis`, `gql_finance`, `da_finance`, `nb_finance_medallion`, plus the cross-domain agents and ontology. Downstream inheritance labels dependants | `py infra/purview.py labels` (status, Scanner API); `apply-labels` (Fabric admin `bulkSetLabels`, label GUID from `.env`) | **Blocked**: the tenant setting *Allow users to apply sensitivity labels* is rejected until Purview labels are **published** to the admin. All 12 items are unlabeled | Microsoft 365 E3/E5 or AIP P1+ (Purview Information Protection); labels created and published in the Purview portal |
| Label inheritance | From data sources, downstream, and domain default labels (preview) | Tenant settings (`infra/tenant_settings.py`, optional entries) | Off (same prerequisite) | As above |
| **DLP** | Detect email/phone PII in Fabric semantic models and lakehouses of the finance workspaces; policy tip + incident report; optional restrict access | [dlp-fabric.ps1](dlp-fabric.ps1) (Security & Compliance PowerShell, interactive) or Purview portal → DLP → *Fabric and Power BI* location | Template only (needs an interactive compliance sign-in + licensing) | **M365 E5 / E5 Compliance** (or the DLP add-on); Fabric capacity; lakehouse DLP is **preview** |
| **Audit** | Who viewed, exported or shared finance items; agent queries; OneLake role and permission changes | `py infra/purview.py audit` (admin activity events = the Fabric slice of the unified audit log; users hashed); Purview portal → Audit for retention/search | **Working**: e.g. `DataAgentFabricQueried`, `CreateOrUpdateDataAccessRoles`, `UpdateFolderAccess`, `ViewReport` | Audit (Standard) with M365 E3; Audit (Premium, 1-year+ retention) with E5 |
| **Data Map / Unified Catalog** | Fabric assets appear in the Purview Unified Catalog *live view* (no scan). External sources (ADLS, Azure SQL) would need a registered source + scan | Purview portal (Data Map → sources) | Live view only. The lab uses Fabric-native substitutes for ADLS/Azure SQL (D-014), so there's nothing external to scan | Live view: included. Classic Data Map scanning: **Purview account (pay-as-you-go)** + SP with read-only admin API access |
| AI interactions | DSPM for AI covers Copilot / data agent prompts | Tenant setting *Allow Microsoft Purview to secure AI interactions* | On | Purview DSPM for AI licensing (E5 class) |
| Purview hub (in Fabric) | Label coverage and sensitive-data insights for admins | Fabric portal → Settings → Microsoft Purview hub | Checklist | Fabric admin |
